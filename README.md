# FizzyInvisKillNameHide

Suppresses death messages involving invisible or vanished players.

Requires Java 21 and Paper 1.21.11. Build and run checks with gradlew.bat build on Windows or sh gradlew build on Linux. The output JAR is under build/libs.

The Paper plugin ID remains HiddenDeathMessages for compatibility with existing configurations. See the plugin descriptor and default configuration for commands and options.
